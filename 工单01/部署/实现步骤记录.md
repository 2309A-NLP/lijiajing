# 工单01 实现步骤记录

## 工单编号
人工智能NLP-Agent数字人项目-记账本任务

## 实现步骤

### Step 1：需求分析
1. 阅读工单PDF，提取核心需求
2. 确定功能：记账、查询、删除、引导补充
3. 确定数据模型：家庭成员、日期、类别、事项、金额
4. 确定技术方案：LLM(NLP解析) + SQLite(存储)

### Step 2：数据库设计
1. 创建 `money_notes` 表
2. 字段：id, member, date, category, item, amount, type, created_at
3. 约束：type CHECK IN ('支出', '收入')

### Step 3：LLM 提示词设计
1. 设计系统提示词，定义4种操作类型：record/query/delete/guide
2. 要求LLM始终返回JSON格式
3. 定义字段映射规则和日期推断逻辑
4. 设置 temperature=0.1 保证输出稳定性

### Step 4：代码实现
1. `config.py` - 配置模块
2. `database.py` - 数据库CRUD操作
3. `agent.py` - LLM调用与回复生成
4. `app.py` - CLI交互主程序

### Step 5：测试
待执行（需要配置LLM API Key后测试）

## 技术要点
1. **信息抽取**：利用LLM的结构化输出能力，从自然语言中提取记账要素
2. **不完整输入引导**：当LLM检测到信息缺失时，返回guide动作，提示用户补充
3. **删除确认机制**：delete操作设置confirm_needed=true，二次确认后执行
4. **日期推断**：将"今天""这个月"等相对时间转换为绝对日期
