# 工单04: PDF文档的图像内容解析及检索优化

## 📋 工单信息
- **工单编号**: 人工智能NLP-RAG-PDF文档的图像内容解析及检索优化
- **创建时间**: 2025年1月（工单01-10）/ 2025年8月（工单11-13）
- **工时预估**: 1-2人日

## 📄 引用的PDF文件
招股说明书1.pdf + 招股说明书2.pdf

## ❓ 测试问题
16个问题：2个图像问题(id 5,6) + 4个力源信息(id 1-4) + 10个兴图新科

## 🎯 任务目标
解析PDF中的图像内容（组织结构图、市场分析图），使用CLIP或多模态大模型。

## ✅ 验收标准
1. 准确率 ≥ 90%
2. id=5（组织结构图）和id=6（IC市场增长图）必须准确
3. 响应时间 ≤ 3秒

## 🏗️ 系统架构
双PDF解析（同工单03）。
图像解析：使用CLIP或多模态大模型提取PDF中图像的特征并检索。
需要额外安装：pip install transformers Pillow

## 📝 备注
id=5需要解析武汉力源信息的组织结构图，id=6需要解析2008年中国IC市场应用结构与增长图。这是最复杂的工单之一，需要多模态能力。

---

> ⚠️ **独立性说明**: 本工单独立运行，所有代码和配置均在本目录下，不依赖其他工单。
> 
> **运行方式**:
> 1. `python pdf_parser.py` — 解析PDF，生成chunks
> 2. `python vector_store.py` — 构建向量库（FAISS）
> 3. `python qa_engine.py` — 启动问答引擎
> 4. `python app.py` — 启动Web界面
>
> **环境配置**: Python 3.12, 需要安装 PyMuPDF, sentence-transformers, faiss-cpu, langchain-ollama
