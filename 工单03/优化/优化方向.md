# 工单03 优化方向：基于 Agent 的文生图任务系统

## 1. Prompt 优化工程
- **当前方案**：直接将用户输入透传给图像生成 API。
- **优化方向**：
  - 增加 LLM Prompt 润色模块，将简短描述（如“一只猫”）扩展为高质量绘画提示词（添加风格、光影、构图等细节）。
  - 支持负面提示词（Negative Prompt）自动注入，避免生成畸形结果。

## 2. 多模型适配与降级
- **当前方案**：固定对接单一图像生成 API。
- **优化方向**：
  - 实现多后端路由（DALL-E 3 / Stable Diffusion / Midjourney API / 本地 ComfyUI），根据请求类型自动选择最优模型。
  - 主服务不可用时自动降级至备用 API，保障可用性。

## 3. 图像后处理与增强
- **当前方案**：直接返回原始生成图片。
- **优化方向**：
  - 集成超分辨率放大（如 Real-ESRGAN），提升输出图片清晰度。
  - 自动添加水印/版权信息，支持一键裁剪与格式转换（PNG/JPG/WebP）。

## 4. 生成队列与异步处理
- **当前方案**：同步等待 API 返回，长请求易超时。
- **优化方向**：
  - 引入异步任务队列（Celery/Redis Queue），大模型生成任务后台执行，客户端轮询状态或接收 WebSocket 推送。
  - 增加生成进度提示与预计完成时间。

## 5. 内容安全审核
- **当前方案**：依赖上游 API 自带过滤。
- **优化方向**：
  - 前置 NSFW 内容检测（如 `nudenet` 或 CLIP 过滤），拦截违规 Prompt。
  - 生成后二次审核，敏感图片自动打码或替换。
