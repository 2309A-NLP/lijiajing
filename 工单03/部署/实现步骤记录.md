# 工单03 实现步骤记录

## 工单编号
人工智能NLP-Agent数字人项目-文生图智能体任务

## 实现步骤

### Step 1：需求分析
1. 阅读工单PDF，提取核心需求
2. 确定功能：面部多角度生成、文生图、扩图
3. NLP重点：LLM提示词优化（中文描述→英文专业提示词）
4. 技术方案：LLM(意图识别+提示词优化) + 图像生成API

### Step 2：提示词优化设计
1. 系统提示词定义4个视角的生成要求
2. LLM提取面部特征，生成一致的英文提示词
3. 正面/左转30°/右转30°/扩图分别处理
4. 负面提示词统一使用通用模板

### Step 3：多后端图像API
1. 支持 SiliconFlow / OpenAI DALL-E 3 / 本地SD / 模拟模式
2. 通过环境变量 IMAGE_API_TYPE 切换
3. 统一 generate_image() 接口

### Step 4：代码实现
1. `config.py` - 配置模块
2. `image_api.py` - 图像生成API封装（4种后端）
3. `agent.py` - 意图识别 + 提示词优化 + 结果格式化
4. `app.py` - CLI交互主程序

## 技术要点
1. **提示词优化**：LLM将中文面部描述转为专业级英文图像生成提示词
2. **特征一致性**：相同面部特征描述嵌入所有4个视角的提示词中
3. **多后端兼容**：统一接口支持多种图像生成服务
4. **模拟模式**：无API Key时仍可运行，生成占位文件

## 已知问题
- 需要配置有效的图像API Key才能生成真实图片
- 面部多角度生成依赖API的图像理解能力（图生图）
- 当前版本为文生图模式，纯图生图需要额外传入参考图像
