# 工单04 实现步骤记录

## 工单编号
人工智能NLP-Agent数字人项目-基金问答智能体任务

## 实现步骤

### Step 1：需求分析
1. 阅读工单PDF，提取核心需求
2. 确定功能：NL2SQL、10张基金表查询、结果总结、批量处理
3. 确定技术方案：LLM(NL2SQL生成) + SQLite(执行) + LLM(结果总结)

### Step 2：NL2SQL 提示词设计
1. 注入10张数据库表的 Schema 信息到系统提示词
2. 规则定义：SQLite语法、日期格式、涨跌幅公式
3. 输出约束：只输出SQL，无解释
4. 多表关联：使用 JOIN

### Step 3：结果总结
1. 查询结果 JSON 化后注入 LLM
2. LLM 生成简洁中文回答
3. 空结果和错误情况的处理

### Step 4：代码实现
1. `config.py` - 配置模块（表结构DDL + 提示词）
2. `database.py` - SQLite操作 + Schema动态提取
3. `agent.py` - NL2SQL生成 + 结果总结
4. `app.py` - CLI主程序（交互模式 + 批量模式）

## 技术要点
1. **NL2SQL**：将 Schema 信息完整注入LLM提示词，提高SQL生成准确率
2. **动态Schema**：如果数据库存在，动态提取实际表结构替代静态DDL
3. **两步处理**：先生SQL再执行，最后用LLM总结结果，避免LLM幻觉
4. **批量模式**：支持 --batch 参数处理 question.jsonl，输出 answers.jsonl
