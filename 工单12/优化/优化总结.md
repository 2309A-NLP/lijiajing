# 工单12 优化点总结

## LightRAG优化项

| 优化项 | 优化前 | 优化后 | 效果 |
|--------|--------|--------|------|
| 实体数量 | 17个 | **43个** | 知识覆盖大幅提升 |
| 关系类型 | 4种 | **12种** | 图谱语义更丰富 |
| 检索策略 | 仅图谱检索 | 图谱+向量双路融合 | 综合效果最优 |
| 实体抽取精度 | 低（通用LLM） | 高（金融领域Prompt） | 准确率提升 |

## 实体类型扩展

```
优化前（4类）：公司、产品、人物、地点

优化后（12类）：
公司、产品、人物、地点、
财务指标、时间段、政策法规、
行业分类、风险因素、投资事件、
监管机构、经济数据
```

## 关系类型扩展

```
新增关系：发布→包含→影响→受监管→竞争→
          投资→并购→子公司→合作→违规→
          受益于→依赖于
```

## 优化结论

精细化的金融领域实体和关系定义是图谱质量提升的核心，Prompt工程对抽取效果影响最大。
