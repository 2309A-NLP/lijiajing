# 工单01 - 基于PDF文档的问答系统 - 过程记录

## 任务概述
基于《招股说明书1.pdf》构建PDF文档问答系统

## 步骤记录

### 1. 项目初始化
- 创建项目基础结构
- 安装依赖

### 2. PDF解析模块
- 使用 MinerU/PyMuPDF 解析招股说明书
- 提取文本内容并分段

### 3. 向量库构建
- 使用嵌入模型将文本向量化
- 存储到向量数据库

### 4. 问答接口
- 构建检索+生成流程
- 对接 LLM 生成答案

### 5. 界面开发
- 构建用户交互界面
- 支持问题输入和答案展示

### 6. 测试验证
- 使用工单提供的10个测试问题验证
- 对比纯 LLM 和 RAG 的结果
