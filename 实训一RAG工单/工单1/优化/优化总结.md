# 工单1 优化点总结

## 初版问题与优化方向

| 问题 | 优化措施 | 效果 |
|------|----------|------|
| 分块过大导致检索噪声 | chunk_size 1000→512，overlap 0→50 | 检索精度提升 |
| 仅取Top-1上下文 | 扩展至Top-5 | 回答覆盖率提升 |
| Prompt无结构 | 加入角色定义+上下文格式 | 回答质量提升 |
| Ollama超时 | 超时时间30s→120s | 稳定性提升 |

## 核心优化：分块策略

**优化前：**
```
chunk_size = 1000
overlap = 0
```

**优化后：**
```
chunk_size = 512
overlap = 50
```

分块更细化，语义更完整，检索更精准。

## 核心优化：LLM回退机制

主用 Qwen2.5（本地GPU，3-4秒/题），不可用时自动切换 DeepSeek API，保障系统稳定运行。
