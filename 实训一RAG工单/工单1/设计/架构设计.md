# 工单1 系统架构设计

## RAG PDF问答系统整体架构

```mermaid
flowchart TD
    A[用户输入问题] --> B[Query处理]
    B --> C[Embedding模型\nBGE-small-zh-v1.5]
    C --> D[向量检索\nMilvus]

    E[PDF文档] --> F[PDF解析\nPyMuPDF]
    F --> G[文本分块\nChunk: 512字符\nOverlap: 50]
    G --> H[向量化\nBGE-small-zh-v1.5]
    H --> D

    D --> I[Top-5 相关片段]
    I --> J[Prompt构建]
    J --> K[LLM生成\nQwen2.5 / DeepSeek]
    K --> L[返回答案]

    style A fill:#4CAF50,color:#fff
    style L fill:#2196F3,color:#fff
    style D fill:#FF9800,color:#fff
```

## 模块说明

| 模块 | 文件 | 功能 |
|------|------|------|
| PDF解析 | pdf_parser.py | 提取PDF文本内容 |
| 向量存储 | vector_store.py | Milvus存取管理 |
| 问答引擎 | qa_engine.py | 检索+生成主逻辑 |
| Web界面 | app.py | Gradio交互界面 |
| 配置管理 | config.py | 参数统一配置 |
