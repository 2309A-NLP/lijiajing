# 工单02: 基于PDF文档的问答系统的优化

## 📋 工单信息
- **工单编号**: 人工智能NLP-RAG-基于PDF文档的问答系统的优化
- **创建时间**: 2025年1月（工单01-10）/ 2025年8月（工单11-13）
- **工时预估**: 1-2人日

## 📄 引用的PDF文件
招股说明书1.pdf（武汉兴图新科，与工单01相同）

## ❓ 测试问题
10个武汉兴图新科问题（与工单01相同）

## 🎯 任务目标
在工单01基础上，优化PDF解析、分块策略、检索策略，提升准确率。

## ✅ 验收标准
1. 准确率 ≥ 90%（需对比优化前后）
2. 响应时间 ≤ 3秒
3. 优化方案对比分析文档

## 🏗️ 系统架构
与工单01相同，但chunk_size改为384（更小分块精度更高），chunk_overlap=48。

## 📝 备注
核心产出是优化前后对比分析，展示精确度提升。尝试不同chunk大小对检索精度的影响。

---

> ⚠️ **独立性说明**: 本工单独立运行，所有代码和配置均在本目录下，不依赖其他工单。
> 
> **运行方式**:
> 1. `python pdf_parser.py` — 解析PDF，生成chunks
> 2. `python vector_store.py` — 构建向量库（FAISS）
> 3. `python qa_engine.py` — 启动问答引擎
> 4. `python app.py` — 启动Web界面
>
> **环境配置**: Python 3.12, 需要安装 PyMuPDF, sentence-transformers, faiss-cpu, langchain-ollama
