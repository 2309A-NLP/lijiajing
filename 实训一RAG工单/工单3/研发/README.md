# 工单03: PDF文档的表格解析及检索优化

## 📋 工单信息
- **工单编号**: 人工智能NLP-RAG-PDF文档的表格解析及检索优化
- **创建时间**: 2025年1月（工单01-10）/ 2025年8月（工单11-13）
- **工时预估**: 1-2人日

## 📄 引用的PDF文件
招股说明书1.pdf（兴图新科） + 招股说明书2.pdf（力源信息，350页）

## ❓ 测试问题
14个问题：4个力源信息(id 1-4) + 10个兴图新科(id 260,95,33,...)

## 🎯 任务目标
新增招股说明书2.pdf（武汉力源信息），使用表格解析技术从PDF表格中提取信息。

## ✅ 验收标准
1. 准确率 ≥ 90%
2. id=1,2,3,4（力源信息表格问题）必须准确无误
3. 响应时间 ≤ 3秒

## 🏗️ 系统架构
双PDF解析：pdf_parser.py支持多PDF（从config.PDF_PATHS读取）。
表格解析定位：分析待检索问题的答案在PDF表格中的位置。

## 📝 备注
招股说明书2.pdf（力源信息）包含大量表格数据（发行信息、关联方、募集资金等），需要使用表格解析技术（如pdfplumber）。

---

> ⚠️ **独立性说明**: 本工单独立运行，所有代码和配置均在本目录下，不依赖其他工单。
> 
> **运行方式**:
> 1. `python pdf_parser.py` — 解析PDF，生成chunks
> 2. `python vector_store.py` — 构建向量库（FAISS）
> 3. `python qa_engine.py` — 启动问答引擎
> 4. `python app.py` — 启动Web界面
>
> **环境配置**: Python 3.12, 需要安装 PyMuPDF, sentence-transformers, faiss-cpu, langchain-ollama
