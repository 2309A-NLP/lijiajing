## ❓ 10个测试问题（自拟）
根据CCF金融年报内容设计，覆盖盈利分析、风险管理、业务结构等方面：

1. 平安银行2019年的营业收入和净利润分别是多少？同比增长情况如何？
2. 中国平安2019年的保险业务收入是多少？集团的科技业务有哪些布局？
3. 招商银行2019年的不良贷款率和拨备覆盖率分别是多少？
4. 邮储银行2019年的个人存款余额和营业收入分别是多少？
5. 中信证券2020年的主营业务收入构成如何？
6. 中国人寿2020年的总投资收益率和新业务价值分别是多少？
7. 招商证券2021年的营业收入和净利润是多少？
8. 中国太保2021年的保险业务收入是多少？
9. 国泰君安2021年的ROE和净资本分别是多少？
10. 对比分析平安银行和招商银行2019年的零售业务战略差异

## 🎯 任务目标
使用工单01-06的RAG系统，对CCF金融年报数据进行端到端测试和评估。

## ✅ 验收标准
1. 10个问题体现CCF PDF内容的相关性
2. 每个问题有检索结果和评估结果
3. 分析检索结果存在的问题（作为测试报告输出）

## 🏗️ 系统架构
- **PDF解析**: PyMuPDF解析9份年报（pdf_parser.py支持批量处理）
- **向量库**: FAISS + BGE-small-zh (2810个chunks)
- **LLM**: Ollama qwen2.5:latest (通过OpenAI兼容API调用)
- **评估**: RAGAS风格评估（Context Precision + Answer Relevancy）

sample_questions.pdf中提供了4个金融分析示例问题：

> **运行方式**:
> 1. `python pdf_parser.py` — 解析9份CCF年报
> 2. `python vector_store.py` — 构建FAISS向量库
> 3. `python qa_engine.py` — 启动问答引擎
> 4. `python app.py` — 启动Web界面
>
> **环境**: Python 3.12 + PyMuPDF + sentence-transformers + faiss-cpu + langchain-ollama
