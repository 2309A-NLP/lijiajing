# 工单17 - 多模态知识检索 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn, numpy

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python app.py
```

### 3. 访问服务
- 打开浏览器访问：http://localhost:8027

## 目录结构
```
work_order_17_多模态知识检索/
├── app.py                      # FastAPI入口
├── config.py                   # 配置文件

```
