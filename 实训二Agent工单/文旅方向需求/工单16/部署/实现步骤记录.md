# 工单16 - 文旅需求分析 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python app.py
```

### 3. 访问服务
- 打开浏览器访问：http://localhost:8026
