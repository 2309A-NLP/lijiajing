# 工单17 - 智能备课系统 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python app.py
```

### 3. 访问服务
- 打开浏览器访问：http://localhost:8017

## 目录结构
```
work_order_17_智能备课/
├── app.py              # FastAPI入口
├── config.py           # 配置文件
├── lesson_planner.py   # 备课核心逻辑
├── README.md           # 设计文档
└── requirements.txt    # 依赖清单
```
