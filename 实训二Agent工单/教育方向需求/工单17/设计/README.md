# 教育智能体 - 智能备课系统

> 工单编号：人工智能NLP-Agent数字人项目-work_order_17_智能备课

## 概述

基于 LLM 的智能备课辅助系统，支持课程大纲自动生成、教学资源智能推荐、课件自动编排、教学目标对齐检查。

## 核心功能

1. **课程大纲自动生成** - 根据主题/学科/年级自动生成教学大纲
2. **教学资源智能推荐** - 基于知识图谱匹配相关教学资源
3. **课件自动编排** - 自动生成幻灯片结构和时间分配
4. **教学目标对齐检查** - 基于 Bloom 教育目标分类法检查目标覆盖度

## 技术方案

1. **LLM 生成教案大纲** - 模拟 LLM 生成结构化教学内容
2. **知识图谱匹配资源** - 基于学科-资源映射的智能推荐
3. **FastAPI + Bootstrap 5** - 暗黑风 Web 交互界面
4. **Bloom 教育目标分类** - 记忆/理解/应用/分析/评价/创造 六层目标体系
