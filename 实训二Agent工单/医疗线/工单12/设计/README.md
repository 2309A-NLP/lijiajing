# 工单 12：健康咨询 (Neo4j 知识图谱)

> 工单编号：人工智能NLP-Agent数字人项目-12-健康咨询

## 功能概述

实现基于知识图谱的医疗健康咨询 Agent，支持：
- 从 `medical.json` 构建知识图谱（实体节点 + 关系边）
- 用户 Query 解析 → 疾病实体识别 → 知识图谱查询 → LLM 生成回答
- 覆盖病原体、传播途径、症状、实验室检查、药物、并发症、中医治疗、预防措施、护理要点、饮食禁忌 10 大维度

## 技术架构

```
medical.json (知识图谱数据)
    ↓
kg_builder.py (导入 SQLite，模拟 Neo4j Node/Edge 结构)
    ↓
kg_agent.py (实体识别 → 图谱查询 → LLM 回答)
    ↓
app.py (CLI 交互入口)
```

**设计说明：** 使用 SQLite 模拟 Neo4j 图数据库结构（节点表 + 边表），无需额外安装 Neo4j 服务，保留 Cypher 查询语义，降低部署门槛。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行测试案例 (百日咳 10 场景)
python3 kg_agent.py

# 3. CLI 交互模式
python3 app.py
```
