# 工单12 - 健康咨询 部署实现步骤

## 环境要求
- Python 3.8+
- Neo4j 数据库（可选）
- 依赖包：gradio, openai, neo4j

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
export DASHSCOPE_API_KEY="your-api-key"
```

### 3. 构建知识图谱
```bash
python kg_builder.py
```

### 4. 启动服务
```bash
python app.py
```

### 5. 访问服务
- 打开浏览器访问：http://localhost:7860

## 目录结构
```
work_order_12_健康咨询/
├── agent.py          # Agent核心逻辑
├── app.py            # Gradio UI入口
├── config.py         # 配置文件

├── kg_agent.py       # 知识图谱查询

```
