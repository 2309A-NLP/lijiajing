# 工单15 - 语音识别与会议纪要 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn, websockets

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
export TINGWU_APP_KEY="your-app-key"
export TINGWU_AK="your-ak"
export TINGWU_SK="your-sk"
```

### 3. 启动服务
```bash
python app.py
```

### 4. 访问服务
- 打开浏览器访问：http://localhost:8015

## 目录结构
