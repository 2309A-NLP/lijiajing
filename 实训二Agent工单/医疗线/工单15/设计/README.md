# 工单 15：实时语音识别、翻译与会议纪要

> 工单编号：人工智能NLP-Agent数字人项目-15-实时语音识别、翻译与会议纪要

## 功能概述

对接通义听悟 API，实现：
1. **实时语音识别** - WebSocket 实时音频流转文字
2. **实时翻译** - 中英日多语种实时翻译
3. **章节速览** - 自动分段，生成章节摘要
4. **要点提炼** - 提取关键信息
5. **摘要总结** - 全文摘要、发言总结、待办事项、关键词
6. **回调机制** - 支持回调 URL + 轮询两种结果获取方式

## 技术架构

```
用户录音 → WebSocket 实时流 → 语音识别引擎 → 实时转写 + 翻译
    ↓ (停止)
会议摘要生成: 全文摘要 / 章节速览 / 发言总结 / 待办 / 关键词
```

## 快速开始

```bash
pip install -r requirements.txt
python app.py  # http://localhost:8015
```

## 协议说明

| 协议 | 用途 | 说明 |
|------|------|------|
| WebSocket | 实时识别 | 双向通信，音频流实时推送 |
| HTTP POST | 回调通知 | 任务完成后推送摘要结果 |
| HTTP GET | 轮询查询 | 主动查询任务状态和结果 |
