# 文旅智能体 - 智能导览

> 工单编号：人工智能NLP-Agent数字人项目-work_order_18_智能导览

## 概述

AI 驱动的智慧景区导览系统，支持语音导览生成、LBS 位置感知推荐、景点文化解说、个性化游览路线。

## 核心功能

1. **语音导览生成** - 自动生成多语种语音导览脚本
2. **LBS 位置感知推荐** - 基于位置推荐附近景点
3. **景点文化解说** - 智能生成景点历史、文化介绍
4. **个性化游览路线** - 根据时间和兴趣推荐路线

## 技术方案

1. **LLM 生成文化解说** - Qwen2.5-7B-Instruct
2. **高德地图 LBS** - 位置服务（模拟）
3. **游览路线规划** - 智能路线推荐
4. **多语种语音导览** - 支持中/英/日语

## 启动方式

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python app.py
```

访问：http://localhost:7878
