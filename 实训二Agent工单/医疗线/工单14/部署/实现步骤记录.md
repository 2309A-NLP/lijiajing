# 工单14 - MCP医疗出行服务 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn, httpx

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
export AMAP_API_KEY="your-amap-api-key"
```

### 3. 启动服务
```bash
python app.py
```

### 4. 访问服务
- 打开浏览器访问：http://localhost:8014

## 目录结构
```
work_order_14_MCP/
```
