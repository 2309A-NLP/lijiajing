# 工单13 - 影像分析 部署实现步骤

## 环境要求
- Python 3.8+
- 依赖包：fastapi, uvicorn, openai, pillow

## 部署步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
export DASHSCOPE_API_KEY="your-api-key"
```

### 3. 启动服务
```bash
python app.py
```

### 4. 访问服务
- 打开浏览器访问：http://localhost:8013

## 目录结构
```
work_order_13_影像分析/
├── app.py              # FastAPI入口
├── config.py           # 配置文件
├── image_analyzer.py   # 影像分析核心

├── uploads/            # 上传目录
├── README.md           # 设计文档

```
