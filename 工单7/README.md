# 工单7：功能测试及评估

基于 RAGAS 框架对 RAG 系统进行全面功能测试与量化评估。

## 目录结构

| 文件夹 | 内容 |
|--------|------|
| 设计/ | 测试方案设计 |
| 研发/ | 评估代码（eval_test.py） |
| 测试/ | 评估报告截图与结果 |
| 优化/ | 评估结果分析与改进建议 |
| 部署/ | 评估环境部署说明 |

## 评估指标

- Faithfulness（忠实度）
- Answer Relevancy（答案相关性）
- Context Precision（上下文精确率）
- Context Recall（上下文召回率）
