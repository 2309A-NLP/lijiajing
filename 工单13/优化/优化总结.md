# 工单13 优化点总结

## 性能瓶颈识别与优化

| 阶段 | 优化前耗时 | 优化后耗时 | 优化措施 |
|------|-----------|-----------|----------|
| PDF解析 | ~2.1s | ~0.8s | 缓存已解析文档 |
| Embedding生成 | ~0.6s | ~0.2s | 批量处理+缓存 |
| Milvus检索 | ~0.4s | ~0.15s | 索引参数调优 |
| LLM生成 | ~8s(API) | ~3.5s(本地GPU) | 切换本地Ollama |
| **端到端** | **~11s** | **~4.7s** | **综合优化** |

## 最大瓶颈：LLM推理

LLM生成占总耗时70%以上。解决方案：
- 从 DeepSeek API（网络延迟）切换至 Qwen2.5 本地GPU推理
- RTX 4060 实测 3-4秒/题，提升约2倍

## Milvus索引优化

```python
# 优化前
index_type = "FLAT"   # 暴力搜索，慢

# 优化后
index_type = "IVF_FLAT"
nlist = 128           # 聚类数
nprobe = 16           # 搜索范围
```

## 优化结论

性能优化优先级：LLM本地化 > 文档缓存 > 索引调优 > Embedding批处理。
